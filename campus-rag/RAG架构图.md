## RAG 处理流程

```
用户提问
    │
    ▼
┌─────────────────┐
│  1. 问题分类    │  关键词匹配: 校规/处分/宿舍/奖学金...
└────────┬────────┘
         │
    ┌────┴────┐
    │         │
    ▼         ▼
 校规相关    普通问题
    │         │
    ▼         │
┌─────────┐   │
│2.查询改写│   │  生成多个搜索查询提高召回率
└────┬────┘   │
     │        │
     ▼        │
┌─────────┐   │
│3.向量检索│   │  FAISS L2 距离检索 top-15
└────┬────┘   │
     │        │
     ▼        │
┌─────────┐   │
│4.结果排序│   │  按相似度排序，取 top-8
└────┬────┘   │
     │        │
     └────┬───┘
          │
          ▼
┌─────────────────┐
│  5. LLM 生成    │  DeepSeek API 生成回答
└────────┬────────┘
         │
         ▼
┌─────────────────┐
│  6. 保存对话    │  用户消息 + AI回复 + 检索结果
└─────────────────┘
```

## 文件结构

```
campus-rag/
├── main.py              # Flask 服务端主程序
├── .env                 # 环境变量配置 (不上传)
├── requirements.txt     # Python 依赖
├── start.bat            # Windows 启动脚本
├── RAG架构图.md         # 本文件
├── rag_data/            # 原始文档目录
│   └── demo_rules.txt   # 预置校规内容 (98条)
└── vector_db/           # 本地向量数据库备份
    ├── faiss_index.index
    └── documents.json

~/campus-rag-data/       # 运行时数据目录 (用户目录)
├── faiss_index.index    # FAISS 向量索引
├── documents.json       # 文档切片数据
├── conversations.json   # 对话历史
└── doc_meta.json        # 文档元信息
```

## API 接口

| 接口 | 方法 | 说明 |
|------|------|------|
| `/api/rag/status/` | GET | 获取知识库状态 |
| `/api/rag/chat/` | POST | 发送问题，获取回答 |
| `/api/rag/upload/` | POST | 上传文档进行切片预览 |
| `/api/rag/upload_text/` | POST | 文本粘贴上传 |
| `/api/rag/save/` | POST | 保存切片到知识库 |
| `/api/rag/delete/` | POST | 删除文档 |
| `/api/rag/conversations/` | GET | 获取对话列表 |
| `/api/rag/conversations/` | POST | 创建新对话 |
| `/api/rag/conversations/<id>/messages/` | GET | 获取对话消息 |
| `/api/rag/conversations/delete/` | POST | 删除对话 |
| `/api/rag/conversations/delete_message/` | POST | 删除消息对 |
| `/api/rag/docs/meta/` | GET/POST | 文档元信息管理 |
